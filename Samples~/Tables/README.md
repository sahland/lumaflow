# Tables sample

1. Import **Tables** through Package Manager.
2. Add a GameObject with a `UIDocument` and assign its Panel Settings.
3. Add `TableSample` to the same GameObject and enter Play Mode.

Click headings to sort, check rows to select them, and use previous/next to
change pages. Selection follows the apartment ID after sorting. The source is
an in-memory dataset with no networking. See `Documentation~/Tables.md` for the
public API and performance limits.
